# Flying Dragon

Я написал эту игру для сына, которому тогда было 5 лет. Мы сидели дома во время
самоизоляции от коронавируса, и мне хотелось развлечь себя и скучающего ребёнка.

Игра максимально простая - дракон должен собрать 10 кристаллов и не погибнуть.
Он может летать и стрелять огнём по врагам. Управление — стрелками и пробелом.
Враги не двигаются и умирают от попадания — но бьют, если к ним приблизиться.
После победы или поражения — новую игру можно начать обновлением страницы.

## Разработка

Нужны Node.js 24 и npm. Если установлен nvm:

```sh
nvm use
npm ci
npm run dev
```

Открыть адрес, который выведет Vite. `npm run start:dev` — совместимый псевдоним.
Игровая логика находится в `src/index.js`, сенсорное управление —
в `src/touch-controls.js`, стили — в `src/style.css`,
HTML — в корневом `index.html`, изображения — в `src/img/`.

## Проверки

Перед первым запуском браузерных тестов:

```sh
npx playwright install chromium
```

На Linux может понадобиться `npx playwright install --with-deps chromium`.
Затем:

```sh
npm run check
npm test
npm audit
```

`npm test` сам собирает production-версию, запускает её из подпапки
`/games/flying-dragon/` и проверяет в Chromium загрузку ресурсов, движение,
стрельбу, сбор кристаллов, урон и resize. Для воспроизводимости поле в тестах
получает фиксированную последовательность случайных чисел. Тесты столкновений
размещают объекты в контролируемых позициях, затем используют обычные клавиши.

GitHub Actions запускает установку, синтаксическую проверку, сборку,
браузерные тесты и аудит. При провале тестов сохраняются трассы в артефактах.
Safari и Firefox этим набором не проверяются.

## Сборка и размещение

```sh
npm run build
npm run preview
```

Vite создаёт `dist/`: HTML, CSS, JavaScript и изображения. Сервер Node.js,
база данных и webpack-dev-server на хостинге не нужны. Ссылки на ресурсы
относительные, поэтому сборку можно разместить в корне домена или в подпапке.

1. Выполнить проверки и сборку.
2. Если игра уже опубликована, сохранить её прежний каталог вне web-корня.
3. Загрузить **содержимое** `dist/` в каталог игры, включая `assets/`.
4. Проверить HTTPS, загрузку изображений, управление и resize по конечному URL.

При размещении в подпапке не заменять файлы основного сайта.
Не загружать исходники, `node_modules`, тестовые отчёты или весь репозиторий.
Адрес подпапки должен заканчиваться `/`. Веб-сервер должен отдавать `index.html`
как индексный файл каталога; дополнительный SPA-rewrite игре не нужен.

Изменение размера окна сохраняет текущую игру, переносит объекты пропорционально
и удерживает их внутри поля. В очень маленьком окне спрайты уменьшаются.
На устройствах с сенсорным экраном и coarse pointer появляются экранные стрелки и кнопка «Огонь». Удерживание стрелки повторяет движение; клавиатура продолжает работать.
