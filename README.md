# Flying Dragon

Я написал эту игру в 2020-м году - для сына, которому тогда было 5 лет.
Мы сидели дома во время самоизоляции от коронавируса, и мне хотелось развлечь скучающего ребёнка.

Игра максимально простая - дракон должен собрать 10 кристаллов и не погибнуть.
Он может летать и стрелять огнём по врагам. Управление — стрелками и пробелом.
Враги не двигаются и умирают от попадания — но бьют, если к ним приблизиться.

Недавно сын вспомнил про неё и попросил обновить интерфейс, чтобы играть можно было и с телефона.
Сначала я добавил экранные кнопки — которые просто повторяли физические клавиши.
Но сыну это не понравилось — он хотел, чтобы дракон мог летать в любую сторону.
К следующему вечеру в игре появились джойстик и направление дракона мышкой или пальцем.

Пока сыну интересно - буду дорабатывать. У него ещё много идей и предложений :)

## Разработка

Нужны Node.js 24 и npm. Если установлен nvm:

```sh
nvm use
npm ci
npm run dev
```

## Основные файлы:

- расчёты размеров, поворотов и столкновений — в `src/geometry.ts`,
- отображение состояния через DOM API — в `src/view.ts`,
- объединение команд мыши, джойстика и клавиатуры — в `src/input.ts`,
- полёт к курсору и точке касания — в `src/pointer-controls.ts`,
- обработка касаний — в `src/touch-controls.ts`,
- состояние и игровые правила — в `src/game.ts`,
- цикл анимации — в `src/index.ts`,
- запуск без интернета и регистрация PWA — в `src/pwa.ts`,
- офлайн-кеш — в `worker/service-worker.ts`, список файлов для него собирает `scripts/pwa-build.ts`,
- стили — в `src/style.css`,
- изображения — в `src/img/`,
- разметка — в `index.html`.

## Проверки

Перед первым запуском браузерных тестов установи Chromium:

```sh
npx playwright install chromium
```

На Linux может понадобиться `npx playwright install --with-deps chromium`.
Для тестов публикации нужен Python 3.

Перед отправкой изменений выполни:

```sh
npm run check        # Проверка типов
npm run test:unit    # Тесты игровых правил и управления
npm test             # Проверка игры в браузере
npm run test:deploy  # Тесты публикации и отката
npm audit            # Поиск уязвимостей в зависимостях
```

Браузерные тесты сами собирают игру и проверяют её в Chromium; Safari и Firefox пока не проверяются.

GitHub Actions запускает эти же проверки при отправке изменений.
Pull request запускает только проверки.

## Сборка

```sh
npm run build
npm run preview
```

Vite создаёт статические файлы в `dist/`: HTML, CSS, JavaScript и изображения.
Ссылки на ресурсы относительные, поэтому сборку можно разместить в корне домена или в подпапке.
PWA работает в готовой сборке; в режиме разработки офлайн-кеш отключён.

## Установка на телефон

Открой опубликованную игру в браузере телефона.
На Android выбери в меню Chrome «Установить приложение» или «Добавить на главный экран».
На iPhone открой игру в Safari, нажми «Поделиться» → «На экран “Домой”» и включи «Открыть как веб-приложение», если есть такой переключатель.

После установки запусти игру по иконке при подключении к интернету.
Дождись сообщения «Можно играть без интернета.» в начальной подсказке — после этого можно играть без сети.
Когда новая версия скачается, в правом верхнем углу появится кнопка «Обновить».
Нажатие обновит игру и начнёт новую партию; до этого можно продолжать играть.
Также обновление применится после закрытия всех открытых окон игры.

## Деплой

После push в `master` игра публикуется автоматически, если все проверки прошли успешно.
Статус и логи выкладки доступны в [GitHub Actions](https://github.com/elhini/flying-dragon-game/actions/workflows/ci.yml).
Для повторной публикации запусти workflow `Check and deploy game` через `Run workflow`, выбрав ветку `master`.
При изменении приёмника `scripts/hoster_receiver.py` обнови его на хостинге до выкладки сборки, которая требует этих изменений.
